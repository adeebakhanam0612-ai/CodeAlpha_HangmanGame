# CodeAlpha_HangmanGame

A simple text-based Hangman game built using Python.

## About
The player guesses a hidden word one letter at a time 
with a maximum of 6 incorrect guesses.

## How to Run
1. Make sure Python is installed
2. Open Command Prompt
3. Run: python hangman.py

## Concepts Used
- random module
- while loop
- if-else statements
- strings and lists
